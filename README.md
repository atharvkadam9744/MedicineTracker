# Medicine Tracker System (C++)

A smart medicine reminder and health tracking system built using C++.

## Features
- User Login & Registration
- Add Medicines
- View Medicines
- Update Medicines
- Delete Medicines
- Time-based Reminder Alerts
- File Handling System

## Technologies Used
- C++
- Object Oriented Programming
- File Handling
- Time Functions

## How to Run

Compile:
```bash
g++ main.cpp -o app
```

Run:
```bash
.\app.exe
```
